# Exercise 02 — Password Security

## Objective

Evaluate password practices and understand what makes password usage secure or insecure.

## Exercise Analysis

### Practice 1

Using the same password for multiple services creates additional risk because compromise of one service can expose other accounts.

### Practice 2

Using strong and unique passwords helps reduce the risk of unauthorized access.

### Practice 3

Using predictable information such as names, birthdays, or other personal information can make passwords easier to guess.

## Good Password Practices

- Use unique passwords for important accounts.
- Avoid predictable personal information.
- Use strong passwords or passphrases.
- Use a password manager where appropriate.
- Enable multi-factor authentication where available.

## Lessons Learned

1. Password reuse increases security risk.
2. Unique passwords reduce the impact of an account compromise.
3. MFA provides an additional layer of protection.
